# Palette Quality Benchmark Notes

Phase 1 benchmark list (run manually in extension popup):

1. Stripe.com (marketing-heavy brand colors)
2. Linear.app (dark SaaS UI)
3. Notion.so (neutral-heavy product UI)
4. Shopify.com (vivid accent + neutral base)
5. Github.com (mixed neutral + semantic colors)
6. Vercel.com (high-contrast monochrome style)
7. Airbnb.com (single dominant brand accent)
8. Figma.com (colorful marketing and CTA accents)
9. MDN docs page (docs-oriented color hierarchy)
10. Amazon product page (commerce dense UI)

Manual checks per site:

- A primary color aligns with perceived brand color.
- Accent includes CTA/highlight color if present.
- At least one useful neutral appears for text/background.
- Eight colors are not near-duplicates of one hue.
- Copy-as-image can be pasted into Figma canvas.
- Clipboard fallback via PNG download works.
